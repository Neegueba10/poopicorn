Poopicorn tools dev server

Authoring tools for this game's data. Everything here is dev-only — none of it ships in the 13 KB zip. Each tool writes plain ES modules into src/js/, which the game imports directly.

Art & world

SDFtool/sdf
3D assets from a handful of primitives — spheres, boxes, capsules, tori, melted together and cut apart. Rendered at run time with ambient occlusion, so a sprite that looks pre-rendered costs thirty numbers. The sheet tab picks which models the game bakes, and at which views — eight facings are one model at eight yaws. The anim tab poses one model over time into a clip.
src/js/models/, src/js/sheets/, src/js/clips/
 Stagetool/stage
The level editor: an unbounded plane of parallax layers holding SDF sprite stamps, box collision and tagged objects. P playtests a body against the real collision.
src/js/stages/

Audio

Voxby/soundbox/
Synth music tracker — a few hundred bytes of song data played back by a tiny runtime routine. Export JS, then npm run convert-song into src/js/sounds/.
tools/soundbox/songs/
Started with npm run tools. One server backs every editor above, plus the repo's src/ tree and the save/list APIs they post to.
